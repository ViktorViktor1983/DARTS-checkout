# Политика конфиденциальности приложения Darts Checkout

**Дата последнего обновления:** 24 сентября 2026 г.

## Общие положения

Приложение Darts Checkout разработано Лодкиным Виктором Евгеньевичем (далее — Разработчик) и распространяется бесплатно через магазин приложений RuStore.

Используя приложение, вы соглашаетесь с настоящей Политикой конфиденциальности.

## Какие данные собираются

Приложение **НЕ собирает, НЕ хранит и НЕ передаёт** персональные данные пользователя.

Приложение работает полностью офлайн и не требует подключения к интернету для основной функциональности.

## Разрешения

Приложение запрашивает только те разрешения, которые необходимы для его работы:

- **Доступ к файлам** — только при экспорте и импорте базы данных по инициативе пользователя.

Никакие другие разрешения приложение не запрашивает и не использует.

## Хранение данных

Все данные (пользовательские варианты закрытий, настройки) хранятся **только на устройстве пользователя** во внутренней памяти приложения. Разработчик не имеет доступа к этим данным.

При удалении приложения все данные удаляются вместе с ним.

## Аналитика и реклама

Приложение **НЕ содержит**:
- рекламных баннеров;
- встроенных покупок;
- сторонних SDK аналитики;
- трекеров.

## Сторонние сервисы

Приложение содержит ссылку на страницу разработчика ВКонтакте. При переходе по ссылке применяется политика конфиденциальности соответствующего сервиса.

## Дети

Приложение безопасно для использования детьми. Оно не собирает никаких данных и не имеет возрастных ограничений (0+).

## Изменения в политике

Разработчик оставляет за собой право изменять настоящую Политику конфиденциальности. Актуальная версия всегда доступна по данному адресу.
